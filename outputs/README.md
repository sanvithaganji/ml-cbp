# Outputs Directory

This directory stores real experiment outputs generated by evaluation, dataset inspection, and user interaction.

## Subdirectories and Files
- `metrics/`:
  - `evaluation_summary.json`: Comprehensive metrics comparison table across all models on held-out test set
  - `ablation_study.json`: Image vs Multimodal ablation comparison and delta statistics
  - `confusion_matrix_*.json`: Confusion matrix per model
- `plots/`:
  - `metrics_comparison.png`: Bar chart of Accuracy, Macro Precision, Macro Recall, Macro F1
  - `confusion_matrices.png`: Heatmaps of confusion matrices for each baseline and fusion model
  - `loss_curves_*.png`: Training & validation loss / F1 progression curves
  - `roc_curves.png`: One-vs-Rest ROC curves
  - `environmental_correlation.png`: Sensor distributions across disease classes
- `dataset_inspection_report.json`: Output of `scripts/inspect_dataset.py`
- `predictions_history.db`: SQLite database logging interactive dashboard predictions
